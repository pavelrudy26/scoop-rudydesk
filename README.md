# RudyDesk — Scoop bucket

Install [RudyDesk](https://rudydesk.com) on Windows with [Scoop](https://scoop.sh):

```powershell
scoop bucket add rudydesk https://github.com/pavelrudy26/scoop-rudydesk
scoop install rudydesk/rudydesk
```

This repository contains only the install manifest (download link and SHA-256 of the official build from rudydesk.com).
